# Navinha Arcade v2.2.5 — inimigos animados

## Integrado
- Interceptador Zig-Zag: spritesheet 4x3, movimento/ataque/dano.
- Artilheiro Violeta: spritesheet 4x3, idle/carga de tiro/dano.
- Blindado Bronze: spritesheet 4x3, movimento/carga/dano.
- Divisor Esmeralda: spritesheet 4x3, pulsação/ataque/dano.
- Fragmento Esmeralda: spritesheet 4x3, pulsação/ataque/dano.
- Rotor Ciano: spritesheet 4x3, rotação/movimento/dano.

Os spritesheets foram derivados diretamente dos sprites originais do projeto para preservar o design visual. Todos mantêm transparência e usam WebP otimizado.
